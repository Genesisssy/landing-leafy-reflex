# 📦 Instalación del Proyecto

Clonar el repositorio:

```bash
git clone https://github.com/Genesisssy/landing-leafy-reflex.git
```

Entrar a la carpeta del proyecto:

```bash
cd leafy-landing-reflex
```

Instalar dependencias con Poetry:

```bash
poetry install
```

Ejecutar el proyecto:

```bash
poetry run reflex run
```

---

# ▶️ Ejecución

Después de ejecutar el servidor, abre en el navegador:

```txt
http://localhost:3000
```
